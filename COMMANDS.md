## 📊 Performance Analytics

```
performance             → Show performance index

show performance        → Display metrics
stats / statistics      → Show statistics
how am i doing          → Performance summary
performance report      → Full analytics report
cache stats             → Show cache statistics

show cache              → Display cache info
```

### Performance Metrics Tracked:
- **Overall Score** (0-100): Combined performance grade
- **Accuracy Score**: Command success rate percentage
- **Speed Score**: Response time performance
- **Reliability Score**: Consistency of performance
- **Wake Word Score**: Wake word detection accuracy
- **Category Breakdown**: Per-feature performance

### Cache Features:
- **Response Caching**: O(1) lookup for identical commands
- **Fuzzy Matching**: Detects similar commands (75%+ similarity)
- **Duplicate Detection**: Prevents accidental repeated commands
- **LRU Eviction**: Automatically removes old entries
- **TTL Expiration**: Entries expire after 5 minutes

## 💡 Tips

1. **Single Activation**: Say "Hey Vox" once, then keep giving commands
2. **Natural Speech**: Commands work with natural variations
3. **App Names**: Use partial names (e.g., "chrome" not "Google Chrome")
4. **Combine Actions**: "open chrome then search for weather"
5. **Grid for Precision**: Use `grid` for precise clicking

---

## 🔧 Troubleshooting Commands

If a command doesn't work:
1. Try saying it more clearly
2. Use simpler phrasing
3. Check if the app/feature is available
4. Use `help` to see available commands
